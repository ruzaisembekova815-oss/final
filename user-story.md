# User Stories

## Story 1: Item Listing
- **As a** user who wants to give away unneeded household goods,
- **I want to** post a new gift item with an image, condition, and description,
- **So that** others in the community can find and claim it.

## Acceptance Criteria
- User can enter item title, description, category, condition, age, and image.
- Item is successfully stored in MongoDB.
